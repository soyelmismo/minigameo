## Mission

The game must survive a stress match at a steady 60fps and must not rot from
dead or disconnected code.

1. **Stress match** — write an integration test that drives a LONG match with
   everything happening at once: many minigames entered and exited back to
   back, power-ups spawning, the roulette resolving, style packs applied and
   reverted, impacts firing, the camera shaking, postfx flashing, and the score
   climbing. Run it for a full simulated 300-second match accelerated (you may
   drive `advance()` with big deterministic deltas, as
   `tests/integration/test_full_match.gd` already does). Report:
   - peak node count of the whole scene tree,
   - peak orphan node count (nodes with no parent still alive),
   - whether any timer, tween, connection or instanced scene survived a
     minigame's teardown (AGENTS.md 1.4: after teardown, not a single orphan),
   - wall-clock cost of the simulated match.
2. **Frame-time budget** — headless has no GPU, so measure what you can: the
   CPU cost per simulated frame of the systems the GameLoop drives (match,
   minigames, score, impact, postfx). Assert a generous ceiling and report the
   real numbers so the orchestrator knows the headroom.
3. **Dead code and disconnected code** — find:
   - functions, signals or exported properties that nothing calls or reads,
   - services registered under a name nobody resolves,
   - events emitted with no subscriber (and subscribers to dead events),
   - archetypes or catalog ids that can never be selected,
   - `.tres` files no system loads.
   Report each with path:line and whether it is safe to delete. Use
   `search_files` and read the code; do not guess.
4. **Robustness probes** — for each system, what happens when its dependency is
   missing or null? Verify the degradation is silent and safe, never a script
   error. Report any place that errors or crashes instead of degrading.
