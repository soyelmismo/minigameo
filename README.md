# ARCADE BLOCK: 5 MINUTE OVERDRIVE

A fast-paced 3D arcade game in Godot. You own a stylized city block for five
minutes. Grab power-ups, spin the roulette, and play 36 absurd micro-games —
each one a satirical jab at modern tech culture and everyday life (chatbots
that forget, GPUs that melt, commuters, notifications). Each micro-game
temporarily transforms the look and sound of the world. Max score before the
clock hits zero.

**Documentos / Docs:**
- `scaffold.md` — brief maestro: visión, arquitectura, contratos, roadmap.
- `AGENTS.md` — directivas de trabajo para agentes.
- `docs/` — GDD, catálogo de micro-juegos, arte, audio, contratos, roadmap.

**Stack:** Godot 4.3+ / GDScript / Blender 4.x → glTF / Godot audio buses /
GUT for tests. See §3 of `scaffold.md`.

> **Idioma:** el juego está en inglés; los docs de equipo, en español.
