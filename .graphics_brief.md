## Mission

The world must look premium, not like default primitives. Concretely:

1. **Environment** — the base environment is currently a bare ProceduralSky
   with glow 0.4 and no fog. Build a proper dusk/night-city look: a sky with a
   real gradient and a sun position, volumetric-ish fog that reads as depth,
   and an ambient/tonemap combo that makes the neon pop. Keep
   `background_mode`/`sky` as data in the `.tres`, never in code.
2. **City block** — verify `city_block.gd` produces a readable, dense but
   clean block: sidewalk, road, varied building heights, window emissives that
   light at dusk, props. Keep procedural generation deterministic
   (`SeededRNG`, fixed seed) so the block is identical every run.
3. **Postprocessing** — the PostFXDirector profile must feel intentional:
   bloom/glow tuned so neon bleeds but text stays legible, a vignette that
   focuses the eye, and per-style-pack variation that is visible between packs
   (VHS_90 and BIT_CRUSH must not look identical to NEON_DRIFT). Every number
   belongs in the `.tres`, not in the script (§1.3).
4. **Performance** — this must hold a steady 60fps with 400 draw calls and
   250k triangles as the ceiling (scaffold section 15). Prefer shared
   materials, `Surface`/multi-mesh instancing where the block repeats, and LOD
   or cheap proxies for distant buildings. Measure, do not assume.
