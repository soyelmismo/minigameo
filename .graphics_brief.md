## WHAT IS ALREADY GOOD — DO NOT REDO IT

- `src/world/city_block.gd` already builds the block procedurally with MultiMesh
  window batches and a dusk rim light. Node names are canonical
  (Ground/Streets/Buildings/Props/SpawnPoints) and MUST STAY; several systems
  look them up by name.
- `GameServices.publish(autoload_name, service_name, instance)` is the ONLY
  registration route. Read `src/core/game_services.gd` and resolve with
  `GameServices.lookup(&"camera")` etc. Never reference an autoload by a
  `/root/Name` path (AGENTS.md §1.1). Never add a second registration path.
- `publish()` refuses anything that is not the live autoload singleton, which is
  what stops a test double from clobbering a real service.
